# SSIK IT Consulting & Solutions

Public website for SSIK, an IT and cybersecurity consulting business co-founded in May 2026 by Ontario Tech University classmates Affan Shaikh and Ghayas Sher.

[Visit the live website](https://sil6428.github.io/SSIK-website/index.html)

## Co-founders

- **Shared responsibilities:** Affan and Ghayas jointly handle consulting work, security-control assessment, privacy and regulatory research, and translating findings into stakeholder-ready recommendations.
- **Affan Shaikh:** In addition to the shared co-founder responsibilities, Affan independently designed, built, published, and maintains the multi-page public website and its GitHub Pages deployment.
- **Ghayas Sher:** Holds the same co-founder, consulting, security-assessment, privacy-research, and stakeholder-communication responsibilities as Affan.

## Services presented

- Security baseline reviews
- Cyber risk and control reviews
- Infrastructure review and documentation
- Security policy and IT advisory support
- Phased improvement roadmaps

## Website structure

- `index.html` - company overview and services preview
- `services.html` - consulting service details
- `about.html` - company story, co-founders, values, and approach
- `projects.html` - honest example service scenarios under the public label “How We Help”; no client work is implied
- `booking.html` - structured consultation intake that prepares a reviewable email draft before scheduling
- `contact.html` - contact information and inquiry form that prepares a reviewable email draft
- `privacy.html` - privacy notice for website inquiries and hosting
- `terms.html` - website and consultation-request terms
- `security.html` - responsible disclosure guidance and authorization boundaries
- `contact-mail.js` - shared contact and consultation email-draft logic
- `shared.css` - shared visual system and responsive styling
- `legal.css` - shared policy-page layout
- `site.webmanifest`, `robots.txt`, and `sitemap.xml` - browser and search metadata
- `assets/` - branded favicon, touch icon, and social-sharing image

## Engagement model

The public site presents a five-step process: discovery, written scope, authorization, review and delivery, and follow-up. SSIK's current public offering is intentionally limited to baseline reviews, risk and control reviews, infrastructure documentation, policy and advisory support, and phased improvement planning. It does not advertise penetration testing or formal certification audits.

The site is built with static HTML, CSS, and JavaScript and published through GitHub Pages.
