# SSIK IT Consulting & Solutions

Public website for SSIK, an IT and cybersecurity consulting business co-founded in May 2026 by Ontario Tech University classmates Affan Shaikh and Ghayas Sher.

[Visit the live website](https://sil6428.github.io/SSIK-website/index.html)

## Co-founders

- **Shared responsibilities:** Affan and Ghayas jointly handle consulting work, security-control assessment, privacy and regulatory research, and translating findings into stakeholder-ready recommendations.
- **Affan Shaikh:** In addition to the shared co-founder responsibilities, Affan independently designed, built, published, and maintains the six-page public website and its GitHub Pages deployment.
- **Ghayas Sher:** Holds the same co-founder, consulting, security-assessment, privacy-research, and stakeholder-communication responsibilities as Affan.

## Services presented

- IT security auditing
- Penetration-testing engagements
- IT and cybersecurity risk management
- Infrastructure consulting
- IT policy and advisory support

## Website structure

- `index.html` - company overview and services preview
- `services.html` - consulting service details
- `about.html` - company story, co-founders, values, and approach
- `projects.html` - project and engagement examples
- `booking.html` - consultation request flow
- `contact.html` - contact information and inquiry form
- `shared.css` - shared visual system and responsive styling

The site is built with static HTML, CSS, and JavaScript and published through GitHub Pages.
